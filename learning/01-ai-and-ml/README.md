# 01. AI & Machine Learning Engineering Notes

Comprehensive, first-principles notes on AI/ML topics covered in the curriculum:
- **Transformers & SLMs:** Self-Attention math, RoPE, custom tokenization, building decoder-only models.
- **Pretraining & Alignment:** Pretraining loops, SFT, LoRA/QLoRA, DPO.
- **Inference & RAG:** Serving engines, quantization, table-aware parsing, vector databases, hybrid retrieval, rerankers.
- **Agents & MCP:** Multi-agent architectures and Model Context Protocol integrations.
