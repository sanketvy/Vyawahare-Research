# 02. Spring Boot 3 & Enterprise Microservices Notes

First-principles notes and interview blueprints for backend engineering:
- **Core Spring & Java 21:** Virtual Threads (Project Loom), Bean lifecycles, `@Transactional` proxies.
- **Microservices Design:** API Gateway, JWT security, rate-limiting algorithms.
- **Distributed Systems & Data:** JPA/Hibernate optimization, Redis caching patterns, Kafka event streaming, Quartz scheduling.
- **AI Integration:** High-performance gRPC bridges with Protocol Buffers between Java and Python.
