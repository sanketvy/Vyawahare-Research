# Technology

Deep-dive AI & Machine Learning engineering modules and implementations built from first principles.

### Scope & Modules:
- **Foundations & SLMs:** Transformer architecture implementations, attention mechanisms (MHA, GQA, FlashAttention), financial BPE tokenization.
- **Pretraining & Fine-Tuning:** Pretraining loops on Indian financial corpora; SFT, LoRA/QLoRA, and DPO alignment.
- **Inference Engineering:** Serving (vLLM, TensorRT-LLM, Ollama), quantization (AWQ, GPTQ, GGUF), KV-cache optimization.
- **Context Engineering & RAG:** Table-aware chunking, dense/sparse hybrid search, rerankers, vector database integrations.
- **Agents & MCP:** Multi-agent coordination frameworks and Model Context Protocol (MCP) server implementations.
