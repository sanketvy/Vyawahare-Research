# Playground

Experimental sandbox for rapid prototyping, quick proofs-of-concept, and exploratory testing.

### Scope & Modules:
- **Scratch Scripts:** Quick Python test scripts for scraping, API experiments, and data parsing.
- **Notebooks:** Jupyter notebooks for inspecting embeddings, tokenizers, and model outputs.
- **Exploratory Lab:** Testing new libraries and ideas before integrating them into production modules.
