# Backend

Java Spring Boot enterprise microservices backend for **Vyawahare Research**.

### Scope & Modules:
- **API Gateway & Security:** Routing, rate limiting, and JWT authentication.
- **Research Service:** Core business logic, report lifecycle, earnings calendar schedulers.
- **AI Bridge Service:** High-throughput RPC/REST integration between Spring Boot and Python AI inference engines.
- **Data Persistence:** Spring Data JPA / Hibernate, relational database management, and Redis caching.
