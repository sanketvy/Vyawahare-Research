# Infrastructure

DevOps, containerization, and deployment configurations for **Vyawahare Research**.

### Scope & Modules:
- **Containerization:** Multi-stage Dockerfiles for Python AI services, Spring Boot backend, and React frontend.
- **Orchestration:** Docker Compose for local development; Kubernetes manifests for production.
- **CI/CD:** Automated testing, linting, build pipelines, and model registry integration.
